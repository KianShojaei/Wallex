  • عملکرد سریع، قابل بررسی و قابل اجرای مجدد توسط داور
  • Backtesting و Shadow Testing پیش از بازار واقعی

سیستم‌های بیرونیکد ما (Python)دروازه‌ی ایمنی: هر سفارش از آن می‌گذردیک هسته برای بک‌تست / شدو / زندهچیپ‌ها = فناوری / تکنیک هر جزء

🧰زبان‌ها و کتابخانه‌ها

  • Python 3.12: کل موتور (داده، استراتژی، ریسک، اجرا، بک‌تست)
  • pandas / numpy: اندیکاتورها و پژوهش
  • pydantic: کانفیگ تایپ‌شده و اعتبارسنجی خروجی LLM
  • httpx: کلاینت والکس با retry · openai SDK: گیت‌وی مدل
  • HTML/JS/SVG: داشبورد بدون فریم‌ورک · pytest: ۲۰ تست

🏗️معماری

  • مونولیت ماژولار با رجیستری استراتژی (plugin)
  • یک هسته‌ی تصمیم برای backtest / shadow / live
  • بروکر انتزاعی (Live / Simulated)، بک‌تست رویدادمحور
  • پیکربندی YAML + env (12-factor)، وضعیت روی دیسک، reconcile
  • سرور MCP بدون وابستگی (JSON-RPC 2.0 / Streamable HTTP)

🧪تکنیک‌های تخصصی

  • رژیم با هیسترزیس روی EMA/مومنتوم؛ score → کف اکسپوژر
  • وزن دینامیک با قدرت نسبی دلاری؛ گارد روند هر حامل
  • LLM با خروجی ساخت‌یافته، بریف هر ماژول، کش و replay قطعی
  • سایز با نوسان (1/ATR%)، حد ضرر، DD halt، kill switch
  • اجرای Maker-first، کارمزد درون‌کوینی، بازتوازن بدون کارمزد
  • اعتبارسنجی walk-forward روی ۳۰ روز داده‌ی ۱ دقیقه‌ای
